# Sylpack Tickets · Canal de actualizaciones

Este repositorio solo contiene los paquetes de instalación y actualización de **Sylpack Tickets**.

- `SylpackTickets_Instalador.zip`: instalación desde cero (Sede o Cliente).
- `SylpackTickets_App.zip`: paquete que usa el botón **Actualizaciones** de la app.
- `latest.json`: manifiesto del canal (versión, notas y SHA256).
- `checksums.txt`: verificación SHA256.

Las releases se generan automáticamente al publicar un tag en el repositorio privado. El código fuente no está aquí.

Hecho por **Sylpack - Departamento de Sistemas**.
